Guide

Every tool carries three labels: a category (how it works), a set of scopes (what it tests), and zero or more risk flags (what it does to the machine running it).

Category

agent Runs its own task loop, deciding the next step from what it just found. 22
scanner Runs a fixed set of checks and reports what they found. 20
mcp Serves tools to a model over Model Context Protocol. The model drives. 14
skill Prompts and instructions for a model. No program of its own. 9

Scope

What the tool is pointed at. A tool may cover several.

ad Active Directory: on-premises domain identity. 10
agentic AI agents and the loops they run, as the thing under test. 9
api HTTP and RPC interfaces behind an application. 4
binary Compiled executables and firmware. 7
cloud Provider accounts and their configuration. 2
code Source, in a repository or a diff. 7
entra Entra ID: Microsoft's cloud identity. 2
llm The model itself: its prompts, its guardrails, and what it emits. 11
logging The record of a test: coverage, findings, and the evidence behind them. 1
modfile Serialised model files, whose formats can carry executable code. 5
network Hosts, ports, and traffic. 21
recon Finding what exists, before anything is tested. 15
redteam Adversary emulation across a whole estate. 11
social People: phishing, pretexting, and what they hand over. 1
webapp Browser-facing applications. 25

Risk flags

Answers a question you would otherwise learn the hard way, after cloning. A flag is not a verdict — it tells you what to expect.

root Asks for root or sudo. Expect it to want elevated privileges.
credentials Reads credential paths such as ~/.aws or ~/.ssh.
installs Installs software on your host.
calls out Calls an endpoint the project does not own.
opaque Contains long encoded blobs you cannot read.
binaries Ships compiled binaries you did not build.

Reading a row

Stars and last-updated say whether a project is alive. The flags say what it will do once it runs. A tool with recent commits and no flags is the easiest to try; a tool with root and credentials belongs in a disposable environment.
