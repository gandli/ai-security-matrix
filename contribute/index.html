Contribute

This repository mirrors aisecuritymatrix.com and syncs once a day. The tool list itself is not maintained here, but translations, prose, and the whole presentation layer are ours to own — pull requests welcome.

Submit something

Fill in the form — it opens a pre-filled GitHub issue. No account needed on this site, but GitHub will ask you to sign in before it creates the issue.

Curation happens upstream at aisecuritymatrix.com. This form raises it here as well, so we can track it and link the two.

Scopes

Or do it by hand

Fix a translation via pull request

Open translations.json and rewrite the entry under tools, keyed by the tool's slug: 

{
  "tools": {
    "usestrix-strix": "开源 AI 渗透测试工具，用于发现并修复应用中的漏洞。"
  }
}

The key is the site slug — the last segment of the detail URL, e.g. /tools/usestrix-strix/. Your translation survives the next sync: the scraper only overwrites fields it fetches, and never touches this file.

Report a data problem

If a tool's stars, risk flags, or description look wrong, the cause is usually upstream. Check aisecuritymatrix.com first. If upstream is right and this mirror is wrong, open an issue with the tool link and the expected value.

Improve pages and styling

Page templates live in src/pages/, shared components in src/components/, and every design token and style rule in src/styles/global.css. Read DESIGN.md at the repository root before changing anything — it records the colour, type, and spacing systems.

Run it locally

git clone https://github.com/gandli/ai-security-matrix.git
cd ai-security-matrix
npm install
npm run dev      # http://localhost:4321/ai-security-matrix/

Before opening a pull request, confirm the build and tests pass:

npm run build          # emits 688 static pages
npx playwright test    # end-to-end suite (164 passed)

Pre-flight checklist

  • Both languages updated, when copy changed
  • Checked in both light and dark themes
  • No overflow down to 320px wide
  • npm run build is clean
  • One concern per pull request, so it can be reverted cleanly

About upstream

Curation, categorisation, and the risk-audit criteria are decided by aisecuritymatrix.com. To add a tool or move one between categories, raise it upstream — this mirror picks it up on the next sync.
