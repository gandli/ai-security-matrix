## Mode
**Operate** — visitor completes a task (find + evaluate a tool). Scanability and consistency outrank expression.

## Design-specificity verdict
Grounded. The composition is a data table with risk flags and category color — it could not carry an unrelated product unchanged. The near-black teal + IBM Plex Mono pairing reads as research tooling, not generic SaaS. Risk: without any hero moment, the page opens as a bare table; the brand claim ("curated directory") is carried only by a 1.75rem wordmark and a one-line tagline.

## Cognitive load
- Visible options at decision points: 6 category tabs + 2 view buttons + 6 sortable columns + search = above the >4 threshold, but grouped into distinct affordance bands (tabs / views / columns), so it reads as three small sets rather than one large one. Acceptable.
- No progressive disclosure on the index; detail lives on a separate page. Correct for this surface.

## Emotional journey
- Entry: calm, competent, no marketing noise. Good.
- Valley: the table starts immediately — no moment that communicates "65 curated, checked daily". The credibility claim is invisible.
- Exit: clicking a row opens a substantive detail page. Strong.

## Strengths
1. Faithful, non-generic visual world; tokens carry through to browser surfaces (selection, scrollbar, caret) after this session's pass.
2. Risk flags are first-class — the safety story is structural, not a disclaimer.
3. Bilingual implementation is real (content, not just chrome).

## Priority issues
1. **P1 — No hero moment.** The page opens on a toolbar. Nothing states scale or freshness before the table. *(→ t2 bolder)*
2. **P1 — Category color is latent.** `--cat-agent/scanner/mcp/skill` exist but only appear inside table cells. Tabs, pills, and the stat strip could carry them. *(→ t3 colorize)*
3. **P2 — Table header rhythm.** `thead th` bottom padding is 0.75rem while `tbody td` uses 1rem — the header feels pinched against the first row. *(→ t4 layout)*
4. **P2 — No empty-state recovery.** "No matching tools found." gives the user nothing to click. *(→ t5 harden)*
5. **P3 — Filter state not shareable.** Sort/filter/search reset on reload. *(out of scope this pass; noted in PRODUCT.md debt)*

## Minor observations
- `.tagline` at 0.9375rem/1.625 is well-set; could gain one step of contrast without breaking the palette.
- `pill` line-height is inherited; at 0.6875rem the pill box can look vertically loose on some rows.

## Questions
- Should the hero strip show live counts (65 tools / 4 categories / 17 scopes) or a curated claim? Live counts risk going stale in the markup — they must be data-driven.
