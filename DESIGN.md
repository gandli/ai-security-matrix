## Typography
- **Body:** IBM Plex Sans, 16px base, line-height 1.5
- **Mono:** IBM Plex Mono for data (stars, dates, tags, tool names)
- **Display:** brand title 1.75rem / weight 600 / tracking -0.02em
- **Heading scale:** h1 2rem, h2 1.25rem, static-doc body 0.9375rem
- **Tabular figures:** used for stars, dates, counts (font-variant-numeric: tabular-nums)

## Spacing
- Page container: `max-width: 76rem`, padding `2rem 4rem` desktop → `1.5rem 1.25rem 4rem` mobile
- Grid gap: `1rem` in detail stat grid
- Table cell padding: `0.625rem 0.75rem` (desktop), `0.375rem 0.5rem` (mobile)

## Components

### Header (`.site-header`)
- Flex row, brand left + nav right. Stacks on mobile (≤640px).
- Brand: 22px matrix SVG in `--name` color + "AI Security Matrix" wordmark
- Nav: About / Guide / Submit / Vendors + globe (EN/中文) + theme icon toggle

### Matrix Toolbar
- Category tabs with counts (active = colored underline, inactive = 60% opacity)
- Search box: full-width max 22rem, mono input, "X / 65" match counter
- Table: 6 columns (Last updated, Category, Tool, Scope, Stars, Flags), sortable headers, row hover highlight

### Pills
- `border-radius: 9999px`, padding `0.125rem 0.625rem`, `0.75rem` font
- Scope (teal), access (amber), host (red), unseen (cyan)
- NOT used as decorative cards; only for tags/labels

### Stat Grid (tool detail)
- `repeat(auto-fit, minmax(14rem, 1fr))`, collapses to 2-col on mobile (≤480px)
- Each cell: uppercase label (dead) + large value + optional sub (stale)

### Checklist Table (safety)
- Rows: "What it does to your machine" questions → yes/no/not-checked
- yes → red (#ff373e), no → teal (#009978)

## Behavior
- **Theme:** default dark, toggle persists to localStorage, swaps `data-theme` attribute
- **Language:** `/` (EN) ↔ `/zh/` (ZH), route preserved across switch
- **Table interactions:** instant client-side filter/sort/search, no reload, no spinner
- **Responsive:** header stacks ≤640, table scrolls horizontally ≤768, detail grid 2-col ≤480

## Anti-Patterns Avoided
- No kicker/eyebrow above headings
- No section numbers (01/02/03)
- No gradient text
- No glass/blur decoration
- No emoji standing in for icons (SVG only)
- No card-nesting
- No system display face as display voice (IBM Plex is intentional, matches source)
