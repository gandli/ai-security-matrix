贡献

本仓库是 aisecuritymatrix.com 的社区镜像， 每天自动同步一次。工具清单本身不在这里维护，但翻译、说明文字和展示层完全由本仓库掌控， 欢迎直接提 PR。

提交

填写表单后会自动打开一条预填好的 GitHub Issue。本站不需要登录， 但 GitHub 会要求你先登录才能创建 Issue。

工具收录在上游 aisecuritymatrix.com 完成。在此提交会同时创建 Issue，便于两边追踪。

手动贡献

通过 Pull Request 修正翻译

打开 translations.json， 在 tools 对象中按工具 slug 找到条目并改写： 

{
  "tools": {
    "usestrix-strix": "开源 AI 渗透测试工具，用于发现并修复应用中的漏洞。"
  }
}

键名是站点的工具 slug（即详情页 URL 的最后一段，如 /zh/tools/usestrix-strix/）。 提交后次日同步会自动保留你的译文——同步脚本只覆盖抓取到的字段，不会动这个文件。

报告数据问题

如果某个工具的星级、风险标记或描述与实际不符，问题多半出在上游站点。 请先到 aisecuritymatrix.com 确认； 若上游正确而本仓库错误，请开 issue并附上工具链接与期望值。

改进页面与样式

页面模板在 src/pages/，共享组件在 src/components/， 设计令牌与全部样式在 src/styles/global.css。 改动前请阅读根目录的 DESIGN.md——它记录了配色、字阶与间距系统。

本地运行

git clone https://github.com/gandli/ai-security-matrix.git
cd ai-security-matrix
npm install
npm run dev      # http://localhost:4321/ai-security-matrix/

提交前请确认构建与测试通过：

npm run build          # 生成 688 个静态页
npx playwright test    # 端到端测试（164 passed）

提交前的检查清单

  • 中英文两个版本都改了（若涉及文案）
  • 明暗两种主题都看过
  • 移动端窄至 320px 不溢出
  • npm run build 无错误
  • 一次 PR 只做一件事，便于回滚

关于上游

工具清单的选题、分类与风险审计标准由 aisecuritymatrix.com 制定。 若想新增一个工具或调整分类归属，请在上游提出；本仓库同步后会自动收录。
